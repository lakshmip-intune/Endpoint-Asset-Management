# Endpoint Asset Management

## Overview

PowerShell-based endpoint inventory and reporting solution designed to demonstrate endpoint management, asset tracking, and automation concepts.

## Features

* Import endpoint inventory from CSV
* Search devices by serial number
* Generate inventory reports
* Export inventory data for auditing and tracking

## Technologies Used

* PowerShell
* CSV Data Processing
* Reporting Automation

## Skills Demonstrated

* Endpoint Management
* Asset Tracking
* PowerShell Scripting
* IT Operations
* Reporting & Automation
